# 음운 탐구 활동장

[Claude 원본](https://claude.ai/artifact/7eSH8hHNNnfXGkffxQ9MNB)을 수정할 수 있는 웹페이지로 복제했습니다.

## 수정하기

바꾸고 싶은 문구를 파일에서 검색해 수정하세요.

- `index.html`: 화면에 표시되는 수업 내용
- `styles.css`: 색상, 글꼴과 화면 배치
- `app.js`: 활동 동작과 일부 문제·정답 데이터

GitHub에서 파일을 열고 연필 버튼으로 편집한 뒤 **Commit changes**를 누르면 배포된 페이지에 반영됩니다.

컴퓨터에서 확인하려면 `index.html`을 브라우저로 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

## 답안 저장

현재 입력한 답은 사용하는 브라우저에만 저장됩니다. 다른 기기와 공유되거나 선생님에게 전송되지 않습니다.

## Supabase MCP

이 폴더의 `opencode.json`에 Supabase MCP가 읽기 전용으로 설정되어 있습니다. OpenCode에서 `/mcps`를 열어 Supabase에 로그인한 뒤 사용할 프로젝트를 선택해야 합니다. 아직 웹페이지의 답안은 Supabase에 저장되지 않습니다.

비밀번호나 Supabase 비밀 키는 GitHub에 올리지 마세요.
